  - Type: feature
  - Description: The desktop description panel (`#descSibling`) opens into the same authoring layout — entry textarea, file picker, Generate, Inject — for every phase, including a shipped-and-acknowledged item whose entry is already in TODO.md and merged. This is the first slice of turning the panel into a phase face (option B): introduce a single phase-driven visibility switch, and use it only to hide the authoring controls once they no longer apply. The REVIEW and STUCK faces that fill that space with phase-appropriate content are the next two slices; this entry does not add new content, it only stops showing authoring controls in phases where they are meaningless, so the change is small and reversible.
  - Behavior: When a task's derived phase is `done` (shipped and acknowledged), the panel hides the entry textarea, the file-picker trigger and panel, Generate, and Inject, leaving the phase rail, the section context, and Discuss. In `none`, `draft`, `accept`, `asking`, `drafted`, `stuck`, and `mockup`, the panel renders exactly as it does today — every authoring control visible and functional. The ASKING and STUCK blocks continue to appear in their states unchanged. The switch is derived from `derivePhase` and repaints live: if an open panel's task transitions to `done` (its entry acknowledged elsewhere), the authoring controls disappear on the next refresh; if it leaves `done`, they return. Mobile is untouched.
  - Implementation notes:

    - Hide via the `[hidden]` attribute, and add explicit `[hidden] { display: none }` guards for each affected child. This codebase has repeatedly hit author-level `display` outranking the UA `[hidden]` rule (the `claude*` family and the file-picker panel both carry explicit guards); a hidden control that still shows is the predictable failure here. Do NOT use inline `style.display`.

Note that hiding `.injectBtn` here must not fight `refreshInjectButton`, which independently hides/shows it based on description emptiness — `applyPhaseLayout` gates the whole group by phase, `refreshInjectButton` gates inject within the shown case; the phase gate wins when phase is `done`. Verify the two compose rather than clobber each other.
